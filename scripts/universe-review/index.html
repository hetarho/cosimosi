기획이 화면이 되는 순간

같은 기억, 더 자연스러운 우주.

변경 전 실제 구현과 개선한 구현을 같은 일기로 나란히 살펴보세요.

01 / DEMO-27 · 31

9단계에서 막히던 돌아오기

다른 하늘을 선택하면 약 1초 동안 배경을 보여준 뒤 별을 확대하고 패널을 별 모양으로 자동 이동합니다. 모양까지 바꾼 뒤 돌아가기로 이어집니다. 같은 기본값 재선택은 막았습니다.

02 / DEMO-25

내용까지 가리던 전체 흐림

화면 전체의 흐림을 없앴습니다. 작성·기억·회상 창의 내용은 그대로 읽고, 다음 버튼은 테두리로 구분합니다. 우주 위에는 옅은 음영만 남겼습니다.

03 / VIS-9 · DEMO-30

화면 밖으로 나가던 요지별

기억 별과 요지별의 높이를 함께 계산합니다. 화면 비율과 열린 패널의 공간을 반영해 두 층을 한 화면에 담습니다.

04 / ONB-12 · 13

패널·설명·버튼이 겹치던 배치

설명의 실제 줄바꿈 높이와 화면의 버튼·입력칸을 측정해 빈 공간에 배치합니다. 작성·회상 창은 설명 자리를 확보하고, 뒤쪽 쓰기 버튼은 숨깁니다.

05 / ONB-9 · 20

기다림을 줄인 안내

시간 연출 뒤 정지는 0.8초에서 0.2초로, 데모 자동 설명은 4.5초에서 2.8초로 줄였습니다. 로그인 후 튜토리얼의 읽기 시간은 유지하고 빠른 행동의 완료 신호도 보관합니다.

07 / DEMO-14 · 29

직접 볼 수 있는 단어별 망각

기억의 문장을 상세창 맨 위로 옮겼습니다. 실제 잃어버린 단어만 흐리게 보이고, 남은 단어는 또렷합니다. 세 샘플 모두 이 차이를 볼 수 있는 기억을 안내합니다.

06 / DEMO-20 · VIS-34

같은 시간을 따르는 별과 연출

표시 날짜에 맞춰 요지별이 떠오르고, 새 기억은 시간 이동 뒤에 나타납니다. 배경 점은 작게 낮춰 실제 기억과 구분했습니다.

08 / DEMO-22

눈앞에서 확인하는 회상

창이 사라지고 선택한 별이 가까워진 뒤 변화가 적용됩니다. 빛 고리가 그 별을 짚고, 결과창에서 실제 회상 전후 모습과 밝기를 나란히 확인합니다.
