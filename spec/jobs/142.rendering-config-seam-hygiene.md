# Job 142: Rendering config-seam hygiene (refactor)

> Implementation work doc. Source spec: [code-review/12.frontend-rendering-performance-audit](../code-review/12.frontend-rendering-performance-audit.md).
> /cosimosi:implement-job 142 builds it via the two checklists below. When done, reflect the result into the
> SSOT (plan/policy/values) and set status: done. Write it in English.

Small, sharp cleanups from the review's hygiene cluster: a values key with zero consumers describing a design the
code explicitly rejected (R011), two copies of the camera interaction envelope that disagree (`minDistance` 20 vs
8), three separate `FROZEN_TIME` constants, duplicated trackball feel constants, a dead exported layer (R013), and
the canvas-host defaults that silently duplicate values (`dpr`, `fov`). Independent of the other jobs; safe any
time. (gen:values)

## Acceptance Criteria (from code-review/12 — R011, R013)

- [ ] A1 **`instance_bucket_size` is gone.** The orphaned key is removed from `spec/values.yaml:102-103` and the
      regenerated artifacts (TS + Go twins); nothing references it. (R011 — `InstancedNodeLayer.tsx:113-115`
      documents why the fixed-bucket design was abandoned.)
- [ ] A2 **One camera interaction envelope.** `CameraControls` and `UNIVERSE_CAMERA_RIG` read the same
      min/max-distance source; the 20-vs-8 disagreement is resolved with the intended value decided and noted (the
      rig's `8` is the product envelope unless the design pages say otherwise). The recorded decision that feel
      constants stay code-level (`packages/universe/src/camera-rig.ts:1-3`) is respected — this de-duplicates, it
      does not move them to values.
- [ ] A3 **One `FROZEN_TIME`.** The three copies (StarField 8 / SkySphere 12 / LatentField 8) collapse to a shared
      reduced-motion constant (or per-layer values if the differing 12 is deliberate — decide and document which).
- [ ] A4 **`EdgeLineLayer` is removed or owned.** Default: delete the never-mounted layer and its export
      (`packages/3d-renderer/src/index.ts:78`); if it is kept as the WebGL2-fallback thin-line variant, it gains a
      consumer or a test plus a comment saying so. (R013.)
- [ ] A5 **Canvas-host defaults stop shadowing values.** `UniverseCanvas`'s `dpr = [1, 2]` / `fov = 55` defaults no
      longer silently disagree with `rendering.max_pixel_ratio` / the skin fov — either sourced from VALUES or
      removed in favor of required props (hosts are always mounted through widgets that pass them).
- [ ] A6 **No behavior change except the reconciled `minDistance`** (called out explicitly at review time with a
      before/after zoom check); full gate green.
