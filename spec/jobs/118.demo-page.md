## Acceptance Criteria (from plan/79.demo-page)

<!-- The source spec's acceptance criteria. After building, verify each is true in the running code. -->

- [ ] A1 `/demo` is reachable **without authentication**, registered under `rootRoute` with **no `beforeLoad`**, outside the authenticated subtree, so neither the auth guard nor `PaletteBootstrap` runs on it ([Z1]).
- [ ] A2 Loading, running and completing the whole sequence issues **zero** `apps/api` RPCs, **zero** DB writes and **zero** LLM calls; no AI port is referenced ([Z1], UL §5).
- [ ] A3 `pages/demo` cannot obtain an `ApiTransport`: the demo-scoped lint block bans `@connectrpc/*`, `@cosimosi/api-client`, `@cosimosi/client-cache`, the `*/react` hook entrypoints, `writeMoodColor` / `readMoodColors` / `readMoodColorRecommendations` / `useMoodColorEditor`, and the `widgets`/`features`/`entities` path patterns — while still restating the `three` / `@react-three/fiber` ban ([I13], [00.overview](00.overview.md) §3).
- [ ] A4 **No `isDemo` flag, prop, parameter or branch exists in `packages/*`, `features/*` or `entities/*`**, and this unit defines no pure function of its own ([I13][Z6]).
- [ ] A5 The page mounts its **own** canvas host over the real render layers and the real `packages/force-sim` (inline bridge, `<FrameTick/>`); `UniverseCanvasWidget`, `StardustOverlay`, `UniverseTimeOverlay`, `WritingFlowSheet`, `RecallFlowSheet`, `DeletionFlowSheet` and `DetailPanel`'s provenance/gist reads are never mounted ([Z1]).
- [ ] A6 The ten beats of [Z3] run in order on the visitor's own actions — split, launch, constellation emergence from a shared neuron, dimming + word loss, recall with a seed change, gist rise into the neocortex band, the sky taking the universe's color, the ornament taster, the signup CTA — each stepped by [78.sequence-engine](78.sequence-engine.md) with a caption, a highlighted control and an always-visible skip ([Z3][O2][O4]).
- [ ] A7 Entering `/demo` starts the sequence **every time**, and a replay in the same tab plays the awaken choreography again (the awaken registry and the read models are reset at mount) ([O3]).
- [ ] A8 One `DemoDiarySet` is chosen at random per run and every split result is identical for the same set — only _which set_ varies between runs ([Z4][Z5]).
- [ ] A9 Time travel is free and unbounded: a control advances the demo clock by `demo.time_travel_step_days` with no monotonicity check, no consent modal and no cost, and no such bypass exists in shared code ([Z2][I10][I13]).
- [ ] A10 **No currency, price, cost, quote, purchase, achievement or payment surface renders anywhere on `/demo`**, and no code path from the page reaches a price table or `Decorate` ([Z8], [00.overview](00.overview.md) §3).
- [ ] A11 The ornament taster changes the sky effect, the star variant and the palette **live** from catalog **ids**, and changes no star's position, size, brightness, emotion or seed; bloom and `camera.fov` stay the fixed skin's ([Z3]-9, [I11][V10], [71.ornament-catalog-model](71.ornament-catalog-model.md)).
- [ ] A12 Leaving `/demo` clears the read models, the clock store, the awaken registry and the palette state; nothing is written to `localStorage`, a URL param or a server, so a subsequent signup starts from an empty universe ([Z7][U2]).
- [ ] A13 The `Diary` body shown is rendered verbatim and never rewritten; beat 6 changes only `currentText` and the seed ([I2][I8]).
- [ ] A14 Fixture synapses connect **neurons only**, canonically ordered, and no memory↔memory edge or attraction can exist in the rendered scene ([I4][I6][I5]).
- [ ] A15 All user-visible copy resolves through the i18n seam under `demo_*` in both locales (`lint:raw-strings` passes), in the restrained literary voice, and satisfies [I12]: "inspired by engram theory", no "works like a brain", the 3D positions are never called the brain's coordinates, no therapeutic claim; beat 8 states the honest [M5] definition ([I12][M5], `spec/tech/i18n.md` §2).
- [ ] A16 Mobile parity is **waived in writing** with the admin-console citation, and `steiger` carries the scoped `insignificant-slice` exemption for `pages/demo` ([00.overview](00.overview.md) §4).

## Implementation Checklist

<!-- How to build it, top to bottom. [P] = parallel (different files, no dependency). Flag (gen)/(migrate)/(gen:values). -->

> **Lands after [job 116](116.demo-fixtures-and-mirror.md)** (fixtures + the ten beat ids) **and
> [job 117](117.sequence-engine.md)** (the engine + its chrome). **Web only, by a stated waiver** — the demo is a
> Visitor surface and `00.overview` §4 gives the Visitor web-funnel behaviours only, following the admin-console
> precedent; state the waiver explicitly, because `lint:fsd:layout` does not enforce web↔mobile page peering and an
> unstated waiver is silently broken. Invoke `/fe-architecture`.

**Tuning + route**

- [ ] T001 **(gen:values)** NEW `demo` group with one key: `demo.time_travel_step_days` — universe-days one time-travel
      action advances the demo clock; value confirmed at implement. `pnpm gen:values`.
- [ ] T002 `route-tree.tsx` gains `demoRoute` under `rootRoute` at `/demo` with **no `beforeLoad`**; `route-screens.tsx`
      gains a `DemoRoute` wrapper supplying `onSignUp`, so the page never imports the router (the shipped
      `UniverseRoute` / `LoginRoute` seam). **No deployment change** — the Worker's SPA not-found handling already serves
      any deep link. **No `apps/demo`**: a second app root would duplicate the renderer host, the build and the config
      for a page whose entire value is the real renderer. **No steiger exemption** — a page slice is not "insignificant".

**The isolation boundary — read it as a closure, not an allowlist**

- [ ] T003 One ESLint block scoped to `src/pages/demo/**` in `apps/web/eslint.config.js` banning `@connectrpc/*`
      (the only source of `useTransport()`), `@cosimosi/api-client`, `@cosimosi/client-cache`, the server-backed react
      mirrors (`@cosimosi/universe/react`, `@cosimosi/twinkle/react`, `@cosimosi/memory/react`) and — by `importNames` —
      `@cosimosi/emotion/react`'s `writeMoodColor` · `readMoodColors` · `readMoodColorRecommendations` ·
      `useMoodColorEditor`, plus path patterns matching `widgets/*` · `features/*` · `entities/*` (narrowing the
      normally-legal `pages → widgets` edge: the demo composes `packages/*` directly, as `pages/test` does).
      **Why it needs no symbol allowlist:** every RPC-issuing function in `packages/*` takes an `ApiTransport` first and
      every hook that hides one calls `useTransport()`, so a page starved of both cannot issue a call by accident.
- [ ] T004 Two mechanical traps to close: ESLint flat config **replaces** rule options per matching file, so the demo
      block must **restate** the existing `three` / `@react-three/fiber` ban or the renderer ban is lost for demo files.
      And the positive half — **no `isDemo` flag, prop or branch in `packages/*` · `features/*` · `entities/*`** — is
      discharged by adding none here; `lint:fsd:layout` R4 catches a copy-pasted mirror.
- [ ] T005 Record the precise reading of [Z1]: no `apps/api` RPC, no DB write, no LLM port. Platform telemetry and the
      app-shell auth bootstrap run above every route and are out of scope. **Never mounted here:**
      `UniverseCanvasWidget` (its `useUniverse()` throws unauthenticated), `StardustOverlay`, `UniverseTimeOverlay`,
      `WritingFlowSheet` (its split is an LLM call), `RecallFlowSheet`, `DeletionFlowSheet`, and `DetailPanel`'s
      provenance / gist reads.

**The canvas host**

- [ ] T006 `ui/DemoUniverseScene.tsx` follows the **product widget's** thirteen-layer composition (not the `/test`
      bench): it owns the three read-model singletons while mounted, mounts
      `<SkinProvider defaultSkin={resolveActiveSkin(VALUES.rendering.activeSkin)}>`, and composes inside one
      `<UniverseCanvas>`: `SkySphere` · `StarField` · `NebulaField` · `LatentStarField` · `CellStarLayer` · `StarLayer` ·
      `FilamentLayer` · `BandFog` · `GistStarLayer` · `AwakenNeuron` · `FrameTick` · `PostFX`, with **one deliberate
      divergence** — `CameraControls` (free fly-around) replaces the product's `NavigationRig`, because the demo promises
      free navigation and no camera choreography. Bloom and `camera.fov` stay the fixed skin's, never taster-controlled.
- [ ] T007 Positions come from `createUniverseSimBridge(null)` (the inline main-thread bridge — **no worker**) fed by
      `buildUniverseGraph(snapshot)` over the resolved `UniverseSnapshot`, pumped by `<FrameTick onFrame={pump}/>`.
      Fixtures are written as **domain** shapes straight into the stores, skipping the proto/DTO mappers — so no
      `bigint`↔`int64` handling and no api-client type is imported.
- [ ] T008 Call `resetUniverseUserState()` on **mount**: `useAwakenRegistryStore` is a module-level idempotency registry
      that survives remounts, so without it a second run in the same tab would skip the awaken. Every entry and every
      replay starts from a genuinely clean sandbox.

**The ten beats**

- [ ] T009 `model/anchors.ts` declares `DemoAnchor` and `DemoSignal` — the host-owned unions job 117's `SequenceStep` is
      generic over — naming **only** the demo-local controls in `DemoControlRail` and the outcomes they produce, so a
      typo in the scenario is a compile error and a control the demo does not own has no member to name.
- [ ] T010 `ui/DemoControlRail.tsx` — the demo-local controls the tour highlights. The visitor **acts**: a step carries no
      handler (the engine's model has no action field), so this page binds handlers keyed off the beat id.
- [ ] T011 The ten beat handlers in `model/`: (1) draw a set and show its first diary body verbatim; (2) reveal the
      precomputed split — **no LLM call**; (3) write memories/neurons/synapses into the stores, announce the fresh neuron
      ids to `AwakenNeuron`, set the clock to the diary date; (4) add diaries 2 and 3 so their shared neurons let the sim
      pull the cluster together — **emergent, never modelled**; (5) advance the clock so brightness and texts erode;
      (6) recall one star (`recallCount+1`, last-recall = the demo clock, seed reshaped, `currentText` swapped to the
      fixture's reconsolidated text); (7) advance further so `semanticStage` climbs and gist bodies rise; (8) let the sky
      ramp fill from the universe's own strength-weighted emotions; (9) the taster; (10) `onSignUp` — the only exit.
- [ ] T012 Two mechanics that are easy to get wrong: the **gist timer anchor** the FE `EpisodicMemory` mirror does not
      carry lives in `pages/demo/model` as demo-local state — **no field is added to the shared type**; and the demo clock
      is a mutable ISO date with a single control (advance by `demo.time_travel_step_days`), with **no** monotonicity
      check, launch precondition, sync-consent modal or diary-date constraint — none of that exemption is expressible in
      shared code, because the demo just passes its date down as the `universeTime` prop the layers already accept.
- [ ] T013 "무제한 별가루" is discharged **by absence**, not by a large number: no balance, cost, quote or spend gate is
      rendered or reachable (`features/twinkle-balance-hud`, `features/spend-cost-display` and `widgets/stardust` are all
      banned by T003). A currency figure on a page that never charges is noise at best and a payment smell at worst.

**Beat 9 — the taster ([Z8] structural)**

- [ ] T014 The taster shows a handful of items per kind and imports **catalog ids only** — never the price table, never
      the ownership/selection model, never `Decorate`. `PALETTE` → `applyMoodColors(rows, fallback)` from
      `@cosimosi/emotion/react` (`setMoodPalette` only; the `AccountService`-calling writes are banned by `importNames`),
      re-derived against whatever job 110 lands for palette ids; `BACKGROUND` → set `SkySphere`'s `effect` prop from demo
      state directly (**not** `setSkinKey`, which would also move bloom and fov); `STAR_SHADER` → a `StarShapeKey` in demo
      state through job 110's `createStarShapeBodySource(shape)` plumbing, remounted by the existing star key pattern.
- [ ] T015 The taster does **not** use job 112's preview store — that store is coupled to the save flow and the unowned
      total, i.e. to a price. Keeping the selection in `pages/demo/model` is what makes [Z8] structural (no code path from
      the taster to a total) and keeps `packages/store` ignorant of the demo.

**Nothing carries over, copy, tests, SSOT**

- [ ] T016 On unmount clear everything touched: `resetUniverseUserState()` (three read models, clock store, awaken
      registry, latent-consumed store) and `resetMoodPalette()` so a tasted palette cannot bleed into the landing page or
      a later session; the page's own `model` state dies with the route. No `localStorage`, no URL param, no server call —
      so the demo needs **no** entry in the shared user-state reset registry.
- [ ] T017 i18n under `demo_*`, keys naming a UI role, present in **both** catalogues; mood labels reuse `moodLabel`
      (no `mood_*` keys). `lint:raw-strings` gates it. **[I12] review is a deliverable**: a caption may say the universe
      is _inspired by_ engram theory, may **not** say it works like a brain, may not describe the 3D positions as the
      brain's coordinates, and may make no therapeutic claim; beat 8's caption carries the honest [M5] definition — the
      colour is the mirror of the emotions you re-read, not an average.
- [ ] T018 Tests: the isolation block actually fails a `pages/demo` file importing a transport or a widget (a probe, like
      the shipped boundary probes); a second mount replays the awaken; the clock advances without any monotonic guard;
      unmount leaves the palette and the three stores clean; every beat id has a caption (an exhaustive `Record`, so a
      missing one is a compile error).
- [ ] T019 SSOT at implement: **extend** `spec/policy/ux/demo.md` (job 116 creates it) with the page-facing section —
      the demo is a trailer, always skippable, time travel free and unmetered, **no currency/price/purchase/achievement
      ever**, the taster shows items without cost or ownership, nothing survives leaving. Add the public `/demo` route to
      `spec/tech/web-routing.md` (no `beforeLoad`, outside the authenticated subtree, SPA-served) and record the
      isolation closure — the demo-scoped block, the transport-starvation argument for why it is complete, the
      flat-config restate caveat, and the standing ban on a demo flag in shared code.
