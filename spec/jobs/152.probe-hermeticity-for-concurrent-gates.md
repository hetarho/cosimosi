- [ ] A1 Two overlapping gate invocations (`pnpm lint`/`pnpm test`/`pnpm check` in two

      (oxlint, ESLint, steiger, prettier `format:check`).

      succeed.
- [ ] A5 An interrupted probe leaves nothing visible to other processes (crash-safe cleanup or
      out-of-tree fixtures).

- [ ] T001 Choose and implement the isolation mechanism, preferring out-of-tree fixtures: run
      each probe in a temp workspace that mirrors the app's lint config (path-mapped

      (locking only the probe does not protect an ordinary lint that scans meanwhile).
- [ ] T002 Apply to `scripts/probe-web-boundary.mjs` and `scripts/probe-mobile-boundary.mjs`
      (the `__boundary_probe_*` fixtures under real `pages`/`entities`).
- [ ] T003 Apply to `scripts/probe-demo-isolation.mjs` and `scripts/probe-sequence-isolation.mjs`
      (the `.probe-*` dirs under real product slices).
- [ ] T004 Apply to `scripts/probe-packages-lint.mjs` (fixtures under three real package
      `src` trees).
- [ ] T005 Belt-and-braces: exclude the probe fixture patterns (`**/.probe-*/**`,
      `**/__boundary_probe_*/**`) from oxlint/ESLint/steiger/prettier ordinary scans, so even
      a crashed probe cannot fail an unrelated run.
- [ ] T006 Add the overlap regression test (spawn a probe and an ordinary lint concurrently;
      both must pass) and keep it in `test:guards`.
- [ ] T007 Reflect into `spec/plan/02.quality-gates.md`: the hermeticity rule (probes never
      write into scanned roots) so the next probe follows it.
