## Grounding

- Constitution ([I1]–[I13]): [00.overview](../plan/00.overview.md) §3 (_The constitution_), incl. the v2 risk
  register. Most at risk here, each with its **structural** guard:
  - **[I1] the system does not delete** — the only delete verb reachable from this page is job 91's `Withdraw`,
    which sets `users.deleted_at`. No purge, no hard delete, no per-effect reversal exists in any contract this page
    can reach; the hard sweep is a scheduled `jobs` row owned by job 91. **Absence, not validation.**
  - **[I11]/[V10] customization may not touch meaning** — this page has **no** decoration control of any kind, so
    there is nothing here for a user (or an injected prompt) to set that could reach a star's position, emotion,
    strength, forgetting or gist. **The guarantee is the empty set, not copy.**
  - **[I10] time flows forward only** — `/me` is **time-inert**: it mounts no clock control and issues no RPC that
    advances universe time. The timezone control writes `users.timezone`, and the monotonic `GREATEST` reset anchor
    means a zone change can never shorten the current `SMALL` window or mint a fresh grant — **the UI says so
    plainly rather than hiding it**.
  - **[I2] the original is immutable** — the export hands out the retained `Diary` verbatim (job 57) and offers no
    edit affordance; the diary-management tab has no writable field.
  - **[U1] per-user isolation** — every read here is a user-scoped RPC whose request carries **no `user_id`**; the
    scope comes from `platform.UserScope`, so there is no client-supplied identity to tamper with.
- Architecture (placement): [ARCHITECTURE.md](../ARCHITECTURE.md) **§3.1** (six one-way layers; a `page` composes
  `features` and holds no domain logic; the segment table — `ui` is the only platform-aware code, `model` holds
  types/stores/machines; the app layer is **segmented**, and only `app/routes`|`app/navigation` may import the
  router), **§3.2** (control state in XState, data in Zustand/TanStack Query, server truth **invalidated, never
  polled** — nothing here is a mode machine: the tab is a location (web) or trivial screen state (mobile), and each
  row's edit is an inline `idle → editing → saving` swap plus a mutation status, the shipped `AccountSection`
  `confirming` precedent; a mutation's pending flag is **data**, not control state, and a machine for a two-step
  confirm would be ceremony), **§3.4** (the domain→visual projection is one-way; this page imports no `three` and no
  visual entity), **§3.5** (`model`/`api` and all of `packages/` shared verbatim; a `*.native.tsx` sibling exists
