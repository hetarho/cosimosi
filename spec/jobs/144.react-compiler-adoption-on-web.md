# Job 144: React Compiler adoption on web (refactor)

> Implementation work doc. Source spec: [code-review/12.frontend-rendering-performance-audit](../code-review/12.frontend-rendering-performance-audit.md).
> /cosimosi:implement-job 144 builds it via the two checklists below. When done, reflect the result into the
> SSOT (plan/policy/values) and set status: done. Write it in English.

Adopts React Compiler 1.0 (stable 2025-10) on `apps/web` — automatic memoization across all the canvas-adjacent
React UI, on the React 19.2 the repo already runs. The review's research pass confirmed compatibility posture:
the compiler memoizes render code, not `useFrame` loops, so the R3F idiom is unaffected, but the scene packages
must be spot-checked (mutation-adjacent components may need `"use no memo"`). Staged: lint preset first (zero
risk), compiler second, mobile deferred until web proves it out.

## Acceptance Criteria (from code-review/12 — Candidate Job 9; research pass §A)

- [ ] A1 **The compiler's rules run in lint.** The current `eslint-plugin-react-hooks` in the web lint path is on
      the latest recommended preset (which now carries the compiler rules — `eslint-plugin-react-compiler` is
      deprecated into it); any surfaced violations are fixed or annotated with a reasoned disable.
- [ ] A2 **`apps/web` compiles through React Compiler 1.0** (`babel-plugin-react-compiler` via
      `@vitejs/plugin-react`'s babel option). The build stays green and the bundle-size delta is recorded here.
- [ ] A3 **The scene packages are explicitly dispositioned.** For `packages/universe-render`,
      `packages/3d-renderer`, and the widget layer: either they compile clean under the compiler, or the files that
      must not be compiled carry `"use no memo"` with a one-line why — no silent skips. R3F `useFrame` behavior
      verified unchanged (the canvas renders identically; no new per-frame allocations).
- [ ] A4 **No behavior change.** Full gate green; headless CDP screenshot parity on landing + universe; interaction
      spot-checks (hover glimpse, pick/fly, ornament preview) behave as before. React DevTools confirms memoized
      components ("Memo ✨") on the previously hand-memoized hot paths.
- [ ] A5 **Mobile is deferred on record.** RN/babel adoption is explicitly out of scope here; a note in this doc
      states the trigger for a follow-up (web soak, one release without compiler-attributed regressions).
