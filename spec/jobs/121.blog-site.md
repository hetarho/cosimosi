## Implementation Checklist

<!-- How to build it, top to bottom. [P] = parallel (different files, no dependency). Flag (gen)/(migrate)/(gen:values). -->

> **Lands after [job 120](120.landing-page.md)**, which owns the origin root (its `robots.txt` must already carry
> `Sitemap: …/blog/sitemap.xml`) and creates `policy/ux/public-copy.md`, which this job extends. **Web only, by a stated
> waiver** — a native app has no long-form-article route and Astro has no RN analogue; state it in full, because
> `lint:fsd:layout` does not enforce web↔mobile page peering. **No values key** — every number here is an address, a
> platform spec or content.

**The serving arrangement — two builds, one origin, one asset directory**

- [ ] T001 `apps/blog/astro.config.mjs` — `site` + `base: '/blog'` + `trailingSlash: 'always'` +
      `build.format: 'directory'`. Without `base`, every page 404s its own `_astro/*.css`. `package.json` stays as is
      (`astro` remains the only dependency).
- [ ] T002 `pnpm build:site` — the single Workers Builds command, in this order: build the blog → **build the web** →
      `node scripts/stage-blog.mjs` → `wrangler deploy`. **Step 2 must precede step 3** because Vite empties `outDir`, so
      a copy staged earlier is silently deleted. `scripts/stage-blog.mjs` therefore **fails loudly** when `apps/web/dist`
      is missing or when the staged tree lacks `blog/index.html` / `_astro/` — the ordering bug becomes a build error
      instead of a production 404.
- [ ] T003 `wrangler.jsonc` changes in **exactly one way**: declare `assets.html_handling` explicitly
      (`"auto-trailing-slash"` — the value that resolves a directory index for both `/blog` and `/blog/`; confirm against
      the Cloudflare assets reference at implement) so the behaviour is pinned rather than inherited.
      `assets.directory` and `assets.not_found_handling` are untouched. **Do not** add a second Worker or a `blog.`
      subdomain — both were rejected, and the subdomain would split domain authority and make every landing↔post link
      cross-origin.

**Fix what breaks under a subpath**

- [ ] T004 One absolute-origin helper, and **every internal href derived from `import.meta.env.BASE_URL`** — never a
      literal `/`. `base` does not rewrite authored href strings, so deriving them is the only guard. Replace the three
      hardcoded `siteUrl` literals (`index.astro`, `rss.xml.ts`, `sitemap.xml.ts`) and the `<a href="/">` /
      `<a href="/rss.xml">` / `<link rel="icon" href="/favicon.svg">` authored links.
- [ ] T005 Delete `apps/blog/public/favicon.svg` and `apps/blog/public/robots.txt` — both would claim an origin-root path
      that job 120 owns. The blog references the origin-root `/favicon.svg` (same origin, so it resolves).
- [ ] T006 `src/pages/sitemap.xml.ts` becomes `/blog/sitemap.xml`, enumerating **every non-draft post** (it currently
      claims the origin root and lists one URL). The root sitemap references it.
- [ ] T007 Replace `og.svg` with one committed `public/og-blog.png` (1200×630) — SVG is not rendered by the major social
      crawlers, so shares currently show nothing. Every post falls back to it.

**The content model — one post is one file**

- [ ] T008 `src/content.config.ts` — the `posts` collection whose schema **is** the build-time gate: `title`,
      `description` (authored, never truncated from the body), `pubDate`, `lang: 'ko' | 'en'` (**the whole of [K5]'s
      per-language story**), `pillar` (the closed five-member enum job 120's theory cards resolve against — an unknown
      pillar **fails the build**), `sources` as `{label, doi}[]` with **min 1** (a theory post with no source cannot
      ship), optional `updated`, and `draft` defaulting to false (the only publication switch, excluding a post from
      index, feed and sitemap at once).
- [ ] T009 Routing: `/blog/` (index — non-draft newest first, grouped under their pillar under a heading carrying
      `id="<pillar>"`, each with a `lang` chip), `/blog/<slug>/` (slug = filename), `/blog/rss.xml` (the newest N
      non-draft, N a module constant), `/blog/sitemap.xml`. The feed stays hand-rolled — a dependency to emit thirty
      lines of XML is not earned. Each post's foot shows up to a fixed number of same-pillar posts plus one restrained
      CTA pair (`/demo` and `/`), closing the funnel the landing opens.
- [ ] T010 `layouts/PostLayout.astro` `<head>`: absolute `<link rel="canonical">` at `/blog/<slug>/`, OG/Twitter over the
      absolute `og-blog.png`, `<link rel="alternate" type="application/rss+xml">`, and `BlogPosting` JSON-LD whose
      `citation` entries come from `sources[]` — so the DOIs the schema requires are machine-readable too. Plus a skip
      link and the footer.

**Migration, and the two corrections that are conditions of publication**

- [ ] T011 Split `src/blog.md`'s nine `##` sections into nine collection files and retire `src/blog.md` (the single page
      becomes the index). Slugs are **English kebab-case** (a URL is code) while the prose stays Korean with `lang: ko`.
      The existing "Description(작성자·심화 학습용)" block splits: the 논문·DOI list becomes structured `sources[]`
      rendered as a citations section; the "LLM에 물어보기" prompts stay body content.
- [ ] T012 **Rewrite post 8.** Its claims that emotionally-close stars are bound more tightly, that similar-emotion
      memories attract one another, and that intense memories stay _closer_ describe emotion driving links and distance —
      forbidden by [I3], [I4] and [I7]. Keep the science (Russell's circumplex, mood-congruent recall, McGaugh's amygdala
      modulation) and state what cosimosi actually does: valence becomes **colour**, arousal modulates **strength and the
      forgetting rate**, links emerge from **shared neurons and synapse strength** with emotion excluded, and the radius
      from centre is **self-relevance** — never recency, never emotion. Then describe mood-congruent recall honestly as a
      phenomenon the product does **not** simulate.
- [ ] T013 Remove the footer's `spec/tech/neuroscience.md` link — the file does not exist, the relative href would
      resolve against the app origin, and **repo-internal paths do not belong in public copy**. Name PRD §9 as the
      requirement↔evidence SSOT in prose instead.

**The `/blog/**` miss, stated rather than discovered**

- [ ] T014 `apps/web/src/pages/blog-not-found/` (**NEW**, web-only — it repairs a _URL_ miss and mobile has no URLs) plus
      a public splat route `path: '/blog/$'` under `rootRoute` (sibling of `/login`, `/test`, `/design`), **outside**
      `authenticatedRoute` and with **no `beforeLoad`** — it must never require a session or the diagnostics flag. It
      renders blog-shaped chrome and a link back to `/blog/`. It can never shadow a real post: static assets resolve
      first, so the SPA only executes on a genuine miss.
- [ ] T015 Set `<meta name="robots" content="noindex">` on mount and keep the sitemap listing only real non-draft URLs —
      the mitigations for the soft-404, because `not_found_handling: "single-page-application"` returns **HTTP 200**. A
      true 404 would need a Worker _script_ in front of the assets, which this one-Worker arrangement pins out. Record it
      as the honest limitation rather than absorbing it silently.
- [ ] T016 The three strings go through the i18n seam (`blog_not_found_*`) — `lint:raw-strings` scans `apps/web/src`, so a
      raw literal there fails the gate. **No steiger exemption** — a `pages/*` slice is not "insignificant".

**The copy gate**

- [ ] T017 `scripts/lint-public-copy.mjs` (**NEW**, added to the root `lint` chain) scanning a **declared root list** —
      `apps/blog/src/content/**` in this unit — and failing on brain-equivalence claims, therapeutic/efficacy claims, any
      sentence presenting the 3D coordinates as the brain's real coordinates, and the three mechanics families
      (emotion→position/link, memory↔memory attraction, radius-as-recency). Deliberately a **new** script: the
      ubiquitous-language lint already scans `apps/blog/src` but plan 65 owns its refresh, and two plans editing one gate
      in one sprint is the collision the sprint's single-owner rule prevents. The root list is data, so job 120's message
      catalogue can be added later without re-deciding anything.

**Tests + SSOT**

- [ ] T018 Verify: `pnpm build:site` produces `apps/web/dist/blog/index.html` + `_astro/`; the stage script fails when run
      out of order; both `/blog` and `/blog/` resolve; every post has ≥1 source and a valid pillar (build-time); the nine
      migrated posts each have a canonical absolute URL; the splat route renders without a session and sets `noindex`;
      the pillar enum matches job 120's theory-card ids; `pnpm lint` (with the new script) passes. Note the asymmetry
      rather than relying on it silently: `.astro` files have **no Prettier parser** here, so `format:check` does not
      cover them — markdown content does.
- [ ] T019 SSOT at implement: **extend** `spec/policy/ux/public-copy.md` (job 120 creates it) with the blog-facing
      sections — two theory tiers never mixed (at least one cited source per post), the sharpened _mechanics the code does

      localized (a translation is a separate post with its own slug and `lang`), and no repository-internal path in public
