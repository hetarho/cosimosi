**Background shader work — as-built [T003/T008]**

The emotion backdrop is a **TSL sky-sphere**: `@cosimosi/3d-renderer`'s `SkySphere` layer draws a `BackSide`
sphere enclosing the scene, shaded on its inner surface, its color sampled from the emotion palette via the
`assets/sky/emotion-gradient` ramp texture (a real 3D body wrapping the universe, not a screen-space wash).

- **Thirteen effects, ported from the real react-bits Backgrounds** (`assets/sky/*-sky.ts`, registered in
  `assets/sky/sky-effects.ts` → `SKY_EFFECTS` / `resolveSkyEffect` / `SkyEffectKey`). Each is a pure color-node
  builder `<name>SkyNode({ gradient, time })`; the effect owns only STRUCTURE + MOTION and samples COLOR from
  the ramp, so the emotions drive the hue and the emotion COUNT reshapes the zones.
  - **`faithful` (9)** — track the source shader on the sphere UV: grainient, iridescence, soft-aurora,
    ripple-grid, ferrofluid, plasma-wave, prismatic-burst, floating-lines, evil-eye.
  - **`adapted` (4)** — the source is screen-space 3D or a multi-pass sim that cannot be one sphere-surface
    node, so the LOOK is re-created and tagged honestly: liquid-ether, pixel-snow, pixel-blast, lightfall.
- **Seamless domain (no "2D unrolled onto a sphere"):** effects are driven by the 3D surface DIRECTION
  (`skyDir` = `normalize(positionLocal)`), never the flat equirect `uv()` — which would leave a visible wrap
  seam and pole pinch. Noise effects sample 3D noise on `skyDir` and raymarchers march along it (zero
  artifact, wraps as the camera turns); inherently-2D/radial effects use `skyStereo` (a stereographic chart
  whose single singularity is tucked behind the viewer, faded to black where the effect allows).
- **Per-effect emotion budget:** each registry entry carries `emotionCounts` + `defaultCount` — gradient/field
  effects read many (5–7), discrete-band & radial fewer (2–5), near-monochrome (pixel-snow / evil-eye) 1–2.
- **`SkySphere` takes an `effect` prop**; it repaints the ramp on emotion change and rebuilds the material only
  on effect change (each GPU resource disposed per-change, never cross-disposing the shared gradient/geometry).
- **Wired into `/test`:** the "Emotion sky (3D)" panel (effect switcher + per-effect count) and the ui-test
  `UniverseTabPanel` (the sky-sphere is now inside `EngramUniverseCanvas`; the switcher swaps the enclosing sky).
- The earlier **2D raw-WebGL2** exploration (`apps/web/src/pages/test/lib/backgrounds/*` + "Emotion backdrops"
  panel) is **removed** — `three` stays confined to `@cosimosi/3d-renderer`; no raw GLSL/WebGL in app slices.

Implementation response awaiting reviewer re-check: the urchin phase rate is faster while its

This follow-up uses a close crop of the live field to check the residual low-alpha ring that was

| Round | Dim | Score      | Note                                                                                                      | Status                                            |
| ----- | --- | ---------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| S5    | 2   | Needs-work | The field is softer, but a circular low-alpha boundary remains; make it transparent earlier than the rim. | open — implementation ready for reviewer re-check |

Implementation response awaiting reviewer re-check: the shared edge feather now starts at
`normalView.z = 0.35`, reaches full strength at `0.95`, and is cubed before multiplying the existing

Apple/Metal 3 WebGPU and forced WebGL2 both retained a visible additive field without a shader or
runtime error. External Codex review reported no findings.

### Star-form working review S6 — 2026-07-27

This follow-up checks the softened emotion field against the exact on-screen position of its
contributing star.

| Round | Dim | Score      | Note                                                                                         | Status                                            |
| ----- | --- | ---------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| S6    | 2   | Needs-work | The boundary is softer, but the star does not appear centered in its nebula; align the peak. | open — implementation ready for reviewer re-check |

Implementation response awaiting reviewer re-check: the shared `ColorField` replaces each sphere
kernel with a camera-facing circle billboard whose origin is the contributor's exact coordinate.
Every frame, its instance matrix composes that coordinate with the camera world quaternion and the
existing bleed-radius scale, so camera movement cannot shift the field peak away from the star.
The disc reconstructs the previous sphere-facing radial profile in TSL before applying the S5 edge
feather and intensity, preserving the softened look on the same WebGPU/WebGL2 and web/mobile path.
Fresh Chrome frames kept every field peak aligned at the initial and tumbled camera poses; a clean
forced-WebGL2 mount retained the color and feather with no shader or runtime error. External Codex
review found no code regression and prompted correction of a stale optimistic-launch description.
