## Acceptance Criteria (from plan/77.demo-fixtures-and-mirror)

<!-- The source spec's acceptance criteria. After building, verify each is true in the running code. -->

- [ ] A1 A new pure package `@cosimosi/demo` exists at `packages/demo`, free of React, DOM, native and transport deps, whose manifest declares **only** `@cosimosi/memory`, `@cosimosi/emotion`, `@cosimosi/memory-logic` and `@cosimosi/config`; no other package or app lists `@cosimosi/demo` as a dependency ([I13][Z1], ARCHITECTURE §3.5).
- [ ] A2 `DemoDiarySet` holds **three** diaries and separates locale-free **structure** from a `Record<Locale, …>` **text** half; a set missing text for a supported locale fails typecheck ([Z4][Z5], [K3]).
- [ ] A3 Every diary in every set carries its fully precomputed split: `EpisodicMemory` members with `name`, `Emotion` (`Mood` + intensity), `NeuronActivation` weights, `seed`, four `SemanticStages` texts, and decay-stage texts for stages 1..N where N = `forgetting.stage_word_removal_ratios`' length ([Z5]).
- [ ] A4 Every set declares a non-empty `sharedNeuronIds` tuple, and the fixture-integrity suite proves that at least one `Neuron` is activated by memories from **two or more different diaries** of that set ([Z4], the beat-4 precondition).
- [ ] A5 Every authored `Synapse` is canonically ordered (`neuronAId < neuronBId`), connects two neurons that co-fire in at least one memory, and carries a strength within `[synapse.initial_same_memory, synapse.strength_cap]` ([I6][I4]).
- [ ] A6 Each set covers all three `NeuronType`s, carries at least three distinct `Mood`s, and its beat-6 recall target's mood differs from the set's strength-weighted dominant mood, so beat 8's color shift is visible ([M4][M5], [Z3]-8).
- [ ] A7 The fixture types contain **no** field for a coordinate, `EffectiveBrightness`, `EffectiveStrength`, decay depth, decay stage, gist stage, accessibility weight, `Twinkle` amount or ornament price — every such value is computed by a reused mirror at read time ([I5][I11][Z8], §2.9 #3/#8).
- [ ] A8 `resolveDemoDiarySet(set, locale, epoch)` returns a `UniverseSnapshot` and a `Diary[]` **shape-identical** to `universeFromResponse` / `diariesFromDtos` output, plus a gist-text sidecar; `EpisodicMemory` gains no new field and no `isDemo` branch is introduced in any package ([I13]).
- [ ] A9 Diary dates are authored as integer day offsets and stamped from an `epoch` **parameter**; the package accesses no clock, no randomness and no storage, so the split/emotion/neuron/gist/decay results are byte-identical on every run and only the drawn set and the displayed calendar dates vary ([Z5][Z2]).
- [ ] A10 `pickDemoDiarySet(sets, draw01)` is pure and total over `[0, 1)`, and the pool and set counts are **derived array lengths** with no `values.yaml` key ([Z4] as amended below).
- [ ] A11 `DemoScenario` names the ten [Z3] beats in order and binds each to the fixture member it acts on, including the beat-9 ornament **ids**; it carries no copy, no i18n key, no engine type, no price and no achievement data ([Z3][Z8]).
- [ ] A12 **No new pure domain function is defined in `packages/demo`**, no new `.golden.json` or Go testdata file is added, and the reuse ledger in Design is exhaustive — every derived value the demo displays comes from an existing parity-pinned function ([Z6] as amended in Design; ARCHITECTURE §2.9 #1).
- [ ] A13 The package makes no network, DB or LLM call and imports no `ai` port, no `@cosimosi/api-client` symbol and no server-backed read mirror ([Z1], UL §5).
- [ ] A14 All authored fixture text passes an [I12] review: no "works like a brain" claim, no description of the 3D coordinates as the brain's real coordinates, no therapeutic claim; the voice is literary and restrained, with no decorative emoji, in both locales.
- [ ] A15 The fixture-integrity suite runs in CI as part of `pnpm test` and fails on any violation of criteria 3–6, so an edit that breaks a set's constellation topology is caught by a gate rather than by watching the demo.
- [ ] A16 No rendering-vocabulary word (`star`, `cell-star`, `filament`, `constellation`, `nebula`, `latent-star`) appears in a type, field or identifier in this package (UL §4, §3.4).

## Implementation Checklist

<!-- How to build it, top to bottom. [P] = parallel (different files, no dependency). Flag (gen)/(migrate)/(gen:values). -->

> **Epic P's root, and it lands before the engine** ([job 117](117.sequence-engine.md)) — so nothing here may import a
> sequence type. Frontend-only: no DB, no LLM, no RPC, no migration, no proto. Invoke `/fe-architecture` before creating
> the package.

**The package (`@cosimosi/demo`) — pure, and its dependency list is the guard**

- [ ] T001 `packages/demo/package.json` — dependencies are **exactly** `@cosimosi/memory`, `@cosimosi/emotion`,
      `@cosimosi/memory-logic`, `@cosimosi/config`, and nothing else, ever. `@cosimosi/i18n` may be imported
      **type-only** (for `Locale`), so the package stays IO-free. No `three`, no React, no `@cosimosi/universe`.
      There is deliberately **no `apps/demo` app root** and no `apps/web/src/entities/demo`.
- [ ] T002 `src/diary-set.ts` — the `DemoDiarySet` type in its two halves. **structure** (locale-free domain facts):
      set id, neuron ids + `NeuronType`, per-diary day offset, per-diary memory ids, per-memory `Mood` + `intensity`,
      `NeuronActivation` weights, `seed`, synapse pairs + `strength` + `coActivationCount`, and the declared
      `sharedNeuronIds` as a **non-empty tuple**. **text**: `Record<Locale, …>` over `supportedLocales` holding the diary
      body, memory `name`, `currentText`, the four `SemanticStages` texts, the decay-stage texts and neuron display
      names — the `Record<Locale, …>` type **is** the completeness guard, because a `.ts` data module is outside
      `lint:raw-strings`' reach.
- [ ] T003 The type has **no field** for a position or any coordinate, `EffectiveBrightness`, `EffectiveStrength`,
      `decayDepth`, a stage-at-a-time, an accessibility cost weight, a Twinkle amount or an ornament price. That absence
      is this job's answer to [Z6] — a second TS implementation of the domain math would have nowhere to write its
      output — and it is why [Z8] holds by construction: no price can render on `/demo` because none exists in the data.
- [ ] T004 `src/diary-sets/*.ts` — **three** authored sets of **three** diaries each, one module per set. Both counts are
      **derived array lengths** (`DEMO_DIARY_SETS.length`, the per-set tuple arity), never declared constants:
      three-per-set is structural (two cannot demonstrate reuse, four dilute the beat). Fixture text is public copy —
      review it against [I12] and the restrained literary voice, complete in **every** supported locale.
- [ ] T005 `src/resolve.ts` — `resolveDemoDiarySet(set, locale, epoch)` returning production shapes only: a
      `UniverseSnapshot` (`memories`/`neurons`/`synapses`/`universeTime`, the same interface `universeFromResponse`
      produces, so `buildUniverseGraph`, the three read-model stores, `starChannels`, `cellStarChannels`,
      `filamentChannels`, `currentDecayStage`/`currentDecayText` and `generateLatentField` all get production input), a
      `Diary[]` in `packages/memory`'s mirror shape, and a **text sidecar** for the four gist strings per memory —
      **never** a new field on `EpisodicMemory`, because gist text is a paid `ViewSemantic` read and widening the shared
      mirror would be an `isDemo` leak into `packages/memory`.
- [ ] T006 Derive rather than author the two values that only look like fixture numbers: `baseStrength` =
      `arousalToInitialStrength(createEmotion(mood, intensity).arousal)` (so the demo shows the real arousal-only
      relationship — valence never enters) and `Neuron.connectivity` = the neuron's degree over the set's authored
      synapses, computed at resolve time. `recallCount` starts at 0 and `lastRecalledUniverseTime` at `null`; beat 6's
      recall mutates the page's demo-local copy, never a second fixture variant.
- [ ] T007 Time is **integer day offsets** from the set's own start, never absolute ISO dates. The resolver takes an
      `epoch` ISO date and stamps `diaryDate` / `createdUniverseTime` / `Synapse.lastActivatedUniverseTime` and fills the
      mirror's required `forgettingOffsetDays` (zero for fresh fixtures) from it — a fixture with hardcoded 2026 dates
      would show a 2029 visitor a stale universe, and every reused quantity is a _difference_ of dates.
- [ ] T008 [P] `src/pick.ts` — `pickDemoDiarySet(sets, draw01)`, pure, taking a number in `[0, 1)`. No PRNG and no clock
      anywhere in the package; the page supplies `Math.random()` at the boundary, which is what makes [Z5] structural
      rather than reviewed.
- [ ] T009 `src/scenario.ts` — `DemoScenario`: the **ten beat identifiers of [Z3] in order** (`diary_appears`, `split`,
      `launch`, `constellation`, `time_accelerates`, `recall`, `gist_rise`, `color`, `ornament_taster`, `signup_cta`) plus
      the per-beat bindings (which diary appears first, which memory beat 6 recalls, which rises at beat 7, and the
      `OrnamentKind → ornament id` pairs beat 9 tastes — **ids only, no price**). **No copy, no i18n key, no highlight
      target, no dwell time**: those are the engine's and the page's. This is an identifier union, not a new UL noun —
      the engine-side noun is plan 78's `SequenceStep`.

**The integrity suite — the reason this unit exists**

- [ ] T010 `src/integrity.test.ts`, per set: (1) at least one neuron is activated by memories from **two or more
      different diaries**, and every declared shared neuron really is (the beat-4 precondition); (2) every synapse
      connects two neurons that share a memory, canonically ordered `neuronAId < neuronBId`; (3) all three `NeuronType`s
      appear; (4) ≥3 distinct moods, and the beat-6 recall target's mood is **not** the set's strength-weighted dominant
      mood — otherwise beat 8's colour shift shows nothing and the product's honest promise goes undemonstrated; (5) a
      decay spread wide enough that beat 5 puts the set's memories at different stages, so word loss reads as a gradient.
      This is a **fixture-integrity** suite, not golden parity: data cannot drift, but it can be edited into an invalid
      state.
- [ ] T011 Pin the one reused function that has no golden fixture today: **`slowFactor`** gets a fixture case or a direct
      assertion **before** this package reuses it. Every other reused function is already pinned
      (`effectiveStrength`/`effectiveBrightness`, the forgetting family, the semanticization family) — reuse them, mirror
      nothing.

**SSOT**

- [ ] T012 SSOT at implement: NEW `spec/policy/ux/demo.md` (this unit creates it; plan 79 extends it) recording that the
      demo's data is shipped, fixed and deterministic; that randomness is **set-granular** because a constellation needs
      shared neurons; that every set demonstrates all ten beats; that fixture text is public copy; that no price,
      purchase, achievement or payment data exists in it; and that nothing carries over. Plus the as-built package layout,
      the structure/text split, the resolver contract and the reuse ledger in a NEW `spec/tech/demo-fixtures.md`.
