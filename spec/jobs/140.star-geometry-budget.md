# Job 140: Star geometry budget (refactor)

> Implementation work doc. Source spec: [code-review/12.frontend-rendering-performance-audit](../code-review/12.frontend-rendering-performance-audit.md).
> /cosimosi:implement-job 140 builds it via the two checklists below. When done, reflect the result into the
> SSOT (plan/policy/values) and set status: done. Write it in English.

Puts a number on every triangle the scene ships. Today the purchased star shapes vary per-instance geometry cost by
~900× with no guard (`facet` 20 tris → `urchin` ≈18k tris, R004), the decorative star backdrop alone is ~291k
triangles with no mobile knob (R008), and BandFog compiles four materials that differ by one constant (R012). The
budget lands in `spec/values.yaml` so a future shape/backdrop change has to state its cost. (gen:values)

## Acceptance Criteria (from code-review/12 — R004, R008, R012)

- [ ] A1 **Every star-shape body fits a declared triangle budget.** A per-shape (or global) budget lives in
      `values.yaml`; the heavy shapes (`urchin` 96×96, `contour` 64×64, `plasma` 48×48, `bubble` 40×40) are
      re-authored to fit it — surface detail moved into the TSL fragment/normal path instead of raw subdivision
      where needed — and a test asserts each registered shape's geometry stays under budget, so a new shape PR
      fails loudly instead of shipping a perf cliff. Visual character per shape is preserved (CDP screenshot
      comparison per shape, judged against the design pages).
- [ ] A2 **The star backdrop is values-seamed with a mobile variant.** `StarField`'s count/radius/mote tessellation
      come from `rendering.*` values (web + `_mobile` variants, mirroring `latent_star_count[_mobile]`); both
      widgets pass their platform's numbers; `LatentField`'s mote tessellation joins the same seam. (R008.)
- [ ] A3 **Backdrop motes cost what they need, not 112 tris each.** The spike from the review — billboard/impostor
      quads (or `Points`) for the 1-px motes — is run behind a screenshot comparison; adopted if visually equal,
      or its rejection recorded here with the numbers. Either way the decision is written down.
- [ ] A4 **BandFog is one draw, one material.** The gap-haze discs render as a single instanced (or merged) draw
      with per-slice strength as an instance attribute; fog look identical. (R012.)
- [ ] A5 **No visual regression, no behavior change.** `pnpm gen:values` applied; full gate green; design pages
      (`/design` star-forms/ambient panels) still render every shape/backdrop correctly.
