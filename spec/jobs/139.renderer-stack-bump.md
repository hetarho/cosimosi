Two renderer-critical dependencies are behind on fixes that land exactly on this repo's hottest paths (R005):
`react-native-webgpu` 0.5.16 → **0.8.1** (0.6.0 fixed iOS-simulator instanced-draw instabilities — the whole scene
is instanced draws; 0.6.2 thread-safe native caches; 0.8.0 ships a Jest mock; 0.8.1 texture-copy fix), and three
0.185.0 → **0.185.1** (patch fixes). The audit proposed R3F 9.7.0, but that version is not published: official npm
and GitHub still identify 9.6.1 as latest on 2026-08-05. Recheck at implementation and bump only to an actually
published stable release; do not manufacture a patch target for an unreleased version. **Land this job first,
before job 136**, so 136's screenshot/lifecycle baseline and every later review-12 verification run use the final
renderer stack.
