**Tier 1 — objective deliverables (checkable)**

- [x] A1 A living design-language guideline exists (`spec/tech/design-language.md`, 2D section) documenting:
      typographic system, color-role application (incl. 2D emotion accents), spacing/density/layout & hierarchy,
      elevation/depth, per-primitive visual style + composed chrome patterns, 2D motion, iconography, state treatments.

      all states + the representative composed-screen set) on **web and mobile**.

- [x] A5 The plan-09 a11y baseline is preserved: token color pairs pass documented WCAG contrast; focus rings visible;

- [x] A7 The 2D rubric (hierarchy & focus · typographic rhythm · spacing/density · color-role application & contrast ·

- [x] A8 A feedback ledger records every round's notes, each tracked to `resolved` or `deferred` (deferred listed).
- [x] A9 **DoD:** the design reviewer signs off — every rubric dimension **Meets** and **zero open Blocking** —
      recorded as a dated sign-off. Completion is sign-off-gated and iterative; there is no single sequential pass.

      fill it as decisions land, finalize at sign-off (T016).

**Review substrate — the showcase the designer inspects**

- [x] T003 Build the web design-showcase surface — the full `@cosimosi/ui` primitive catalog in every state
      (default / hover / focus / pressed / disabled / loading). Built as its own page slice + route
      (`apps/web/src/pages/design`, `/design`, behind the diagnostics gate) rather than another `/test` panel: the
      review reads comparisons _across_ sections, which a panel switcher hides, and `/test`'s job is platform wiring
      over a live GPU scene. Static hover/pressed/focus come from `base.css`'s `.state-*` hooks — extra selectors on
      the real rules, never copies of them.
- [x] T004 [P] Add the composed-screen reference set to the web showcase: the writing flow, a star-detail panel mock, a
      HUD, a modal/dialog, a list page, and empty/error states — enough real chrome to judge the language in context.
- [x] T005 [P] Mirror the showcase on mobile (the RN test surface) — same catalog + composed set via the native
      primitive siblings. Deferred until the web language is signed off, so the mirror is built once against a
      settled language rather than tracking it through the review rounds.

**Define + apply the 2D language (the design work — iterated with Tier 2)**

- [x] T006 Typographic system: define scale roles + line-height/measure rhythm; apply via `packages/ui/src/tokens.ts`
      (+ `base.css`); **(gen:tokens)**. Record the rules in the guideline.
- [x] T007 Color-role application: define surface/text/border/state rules + the **2D emotion-accent rules that
      reference plan 57's palette values** (do not author palette values here); adjust `tokens.ts` color roles as
      needed; **(gen:tokens)**; keep contrast passing.
- [x] T008 Spacing / density / layout & information-hierarchy principles; apply to the composed chrome patterns
      (panel / HUD / modal / list) in the showcase.
- [x] T009 Restyle the `@cosimosi/ui` primitives to the component visual style **within plan 09's primitive API**
      (Button, IconButton, Dialog, Toast, Badge, TextField, TextArea, Switch, Checkbox, Tooltip, Skeleton …) — web
      `*.tsx` + `*.native.tsx` siblings, via `primitives/button-styles.ts` etc. No API/behavior changes.
- [x] T010 2D motion / micro-interaction language on `tokens.duration`/`ease` (enter/exit, state feedback);
      **reduced-motion honored** via the existing `a11y/use-reduced-motion`.
- [x] T011 Iconography conventions + state treatments (empty / loading / error / disabled) — documented + shown in the
      showcase.

**Retrofit — first application on live screens**

- [x] T012 Retrofit the shipped Epic A DOM chrome to the language: `apps/web/src/widgets/writing-flow/**` +
      `apps/web/src/features/{write-diary,split-diary,launch-stars,revise-split}/ui/**` and the mobile equivalents

**Guardrails — preserve what Epic A earned**

- [x] T013 Enforce **zero hardcode escapes** (grep guard: no raw hex / `[Npx]` / arbitrary utilities in

**Iterative designer-review loop (Tier 2 — the real DoD)**
