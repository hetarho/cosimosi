      tree fail oxlint / ESLint respectively._

      green)._

- Codex (`gpt-5.5`, read-only) returned three findings, no P1:
  - **P2 — boundary probes no longer exercise the ordinary `lint:boundaries` script (glob drift
    blind spot): APPLIED.** Each boundary probe now asserts the app's gate wiring (`lint` invokes
    the scan; the scan command still carries the full `src/**` glob) and fails on drift.
  - **P3 — stale-workspace sweep could delete a >1h live concurrent workspace: APPLIED.** Threshold
    raised to 24h (leftovers are invisible to every scanner, so lingering costs nothing).
  - **P3 — overlap test is probabilistic; leftover test planted only `.probe-*` under src:
    PARTIALLY APPLIED.** The leftover test now plants all three shapes (`.probe-*` in scanned
    roots, `__boundary_probe_*` under src, `.probe-ws-*` at the app root). The probabilistic
    overlap is kept as-is (rejected): deterministic synchronization would need probe-side pause
    hooks, and the deterministic guarantees already live in the planted-leftover test plus the
    structural fact that fixtures never enter scanned roots; the overlap test is end-to-end sanity
    on top.
