# Job 137: Refetch identity cascade damping (refactor)

> Implementation work doc. Source spec: [code-review/12.frontend-rendering-performance-audit](../code-review/12.frontend-rendering-performance-audit.md).
> /cosimosi:implement-job 137 builds it via the two checklists below. When done, reflect the result into the
> SSOT (plan/policy/values) and set status: done. Write it in English.

The GetUniverse read path propagates **identity** changes with no seam asserting **content** equality, so the
cheapest event in the system (a no-op refetch: 30 s staleTime + window refocus) buys the most expensive work — a sim
worker respawn, a sky TSL shader recompile, and full instance-channel rebuilds (R003). The same
subscription-placement theme puts web hover state in the canvas host (R014). Build after job 136, before job 138
(whose extraction then carries these fixes once).

## Acceptance Criteria (from code-review/12 — R003, R014)

- [ ] A1 **A content-identical GetUniverse refetch is free.** When the response carries the same data, the entity
      stores keep their previous `byId`/`ids` references, the `universe` snapshot keeps its identity, the sim worker
      is not respawned, the sky material is not rebuilt, no instance attributes re-upload, and the canvas host does
      not re-render. (R003.)
- [ ] A2 **Genuine changes still propagate exactly as today.** A launch (optimistic-tail merge preserved), an edit,
      a decay step, an emotion change — each still updates stores/graph/sky; sim continuity across a real graph
      change (coordinate remap + seeding) is unchanged.
- [ ] A3 **The sky material rebuilds on content, not identity.** `SkySphere` recompiles only when the effect key,
      emotion count, weight **values**, opacity, or headroom change — a stops array with identical numbers does not
      rebuild it; color-only changes keep taking the ramp-repaint path.
- [ ] A4 **`bridge.start` with a sim-equivalent graph keeps the running worker** (same node/edge sets and weights →
      no terminate/respawn) — defense in depth beneath A1's store-level bail.
- [ ] A5 **Hovering between stars re-renders only the glimpse surface, not the scene tree.** The hover id moves out
      of `UniverseCanvasHost`; hover UX is pixel-identical. (R014.)
- [ ] A6 **No behavior change / no regression.** All gates green; force-sim golden/parity tests untouched; a
      just-launched star remains immediately pickable.

## Implementation Checklist

- [ ] T001 `packages/universe/src/episodic-memory-store.ts` (+ sibling `neuron-store.ts` · `synapse-store.ts`):
      give `setAll` a content-equality bail — when the incoming collection matches the current one id-for-id (and
      per-item content), keep the existing `byId`/`ids` references. Unit tests: equal input → same references; one
      changed row → new references.
- [ ] T002 `packages/universe/src/react/use-universe.ts:32-35`: make the `universe` snapshot identity-stable across
      content-identical responses — keep the previous snapshot when the newly mapped one deep-equals it (a `useRef`
      compare over the snapshot, or protobuf-es message equality on `query.data` before mapping). This single bail
      stops the graph → `bridge.start` → worker chain and the stops → sky chain at their root. The
      optimistic-launch merge at `:52-63` is load-bearing — the bail must not suppress it.
- [ ] T003 `packages/universe/src/sim-bridge.ts:73-115`: `start(graph)` no-ops (keeps the running worker/sim) when
      the new graph is sim-equivalent to the displayed one — same node ids, same edges, same weights. Extend
      `sim-bridge.test.ts`: equivalent graph → no terminate/respawn; changed graph → today's remap+reseed path.
- [ ] T004 `packages/3d-renderer/src/layers/SkySphere.tsx:103-123`: key the material memo on weight **content**
      (e.g. a fixed-precision join of `weights` + `count`), not array identity; keep the documented
      rebuild-on-structure behavior for count-structured effects. Extend `SkySphere.test.ts`: same-content stops →
      same material instance.
- [ ] T005 `apps/web/src/widgets/universe-canvas/ui/UniverseCanvasWidget.tsx:173-180`: move `hoveredMemoryId` out of
      the host — a small hover store in the widget's `model/` segment (or lift the glimpse label into a sibling that
      alone subscribes); scene layers receive a stable `onHover` writing to the store. Mobile has no hover — the
      fork asymmetry stands, documented.
- [ ] T006 End-to-end assertion of A1: a test (or instrumented probe) firing a refetch with identical data and
      asserting no worker respawn + no material rebuild; then `pnpm check` green.
