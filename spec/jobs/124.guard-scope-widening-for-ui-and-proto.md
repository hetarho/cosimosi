# Job 124: Guard scope widening for ui and proto (refactor)

> Implementation work doc. Source spec: [code-review/10.jobs-94-115-achievement,-decorate-and-sh](../code-review/10.jobs-94-115-achievement,-decorate-and-sh.md).
> /cosimosi:implement-job 124 builds it via the two checklists below. When done, reflect the result into the
> SSOT (plan/policy/values) and set status: done. Write it in English.

Covers the guard half of **R003** and all of **R006** — review 10's _guard scope drifted behind where files actually
live_ theme. Both guards pass today. Neither is wrong about **what** to forbid; both are wrong about **where to look**,
and both were correct when written.

- **R4 (promote-on-reuse) cannot see `features/*/ui`.** `scripts/lint-fsd-layout.mjs:29-30`'s
  `PURE_MODULE_SEGMENT = /(^|\/)(api|model|lib|config|shared)(\/|$)|(^|\/)app\/(providers|model)(\/|$)/` matches no arm
  for a path under `features/<slice>/ui/`, so `lint-fsd-layout.mjs:135-155` skips the pair before hashing it. That is
  how a byte-identical 56-line `AchievementNoticeHost.tsx` shipped in both apps with `pnpm lint:fsd:layout` green — and
  `ui` is precisely where a platform-pure hook shell most plausibly lands. The rule ARCHITECTURE §3.1 states is
  documented-but-unenforced for the whole segment.
- **`lint:comments` cannot see `proto/`.** `scripts/lint-comment-history.mjs` excludes it twice over: `SRC_GLOBS`
  (line 13) omits `proto/`, and `CODE_EXT = /\.(go|[mc]?[jt]sx?|sql)$/` (line 17) does not match `.proto`. So the
  guard's own forbidden pattern `/\bplan[-\s]?\d/i` sits unflagged seven times in
  `proto/cosimosi/memory/v1/memory.proto` (lines 5, 6, 20, 23, 138, 146, 256), and propagates into generated code the
  guard deliberately exempts — reaching `internal/gen/.../memory.pb.go:553` and
  `packages/api-client/src/gen/.../memory_pb.ts:232` while staying invisible. `proto/` is the single transport contract
  shared by the Go server and both TS clients (§2.7): the highest-leverage comment surface in the repo, and the only
  source root the timeless-comment rule is documented for but not enforced on.

Job 123 does the `AchievementNoticeHost` promotion. **This job widens the guard that should have caught it.** Order
matters — see T009.
