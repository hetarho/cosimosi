# T257 A guide caption appears once, already in its measured place

## goal
A guide caption is first painted at the place the layout measured for it. It does not jump after appearing, and it does not blink when a webfont swaps in or the paragraph merely changes size. This applies to the demo and the post-signup tour on web.

## acceptance
- [v] The caption becomes visible only in the same commit that applies its measured position. No imperative reveal precedes React's commit of that position.
- [v] A size-only change of an already placed paragraph (font swap, ResizeObserver tick) re-measures without hiding it. The caption hides only while its layout key or room actually changes.
- [v] Tests:
  - the first visible state carries the measured position, never the preferred fallback
  - a ResizeObserver tick on a placed caption keeps it visible
  - a real room change still hides, then reveals at the new place
  - existing sequence-guide and timing tests stay green
- [v] A cold `/demo` load at 390x844 under 4x CPU and fast-4G throttling, run three times, shows the first visible caption frame at its final position, with no hidden frame after first reveal. The scout's recipe has median CLS above 0 coming from the caption container; after the fix it must not.
- [v] `pnpm lint`, `pnpm typecheck:affected`, `pnpm test:affected` against the assignment start.

## result
- outcome: A guide caption is first painted at its measured place and no longer jumps or blinks, and its live region stays exposed while the line changes.
  - `use-caption-layout.ts` drops both imperative visibility writes (the reveal after `setLayout` and the hide in `schedule()`), so visibility follows only the `layout` state, which commits together with its position.
  - A size tick, scroll, mutation or font swap re-measures the placed line where it stands. Only a change of the surfaces that decide the room (the topmost `aria-modal` or the set of marked panels) clears the layout, hiding the line until it is measured there.
  - In `SequenceCaption.tsx` the `aria-live="polite"` element is a still container that is never hidden and never moves (review 32f1051c P2). The positioned band inside it (`data-sequence-caption-band`) carries the measured place and the visibility, so a new line changes in place inside an exposed live region. The band is never painted at the fallback, and no unhidden box moves into position (hiding only the paragraph had left a moving wrapper counted at CLS 0.1328).
  - With the live region off the measured band, `DemoPage`'s band-height read is retargeted to `[data-sequence-caption-band]`. The coordinator approved that `DemoPage.tsx` change (review 32f1051c decision); it is not in the touches list. The guide test's band selector (`SequenceGuide.test.tsx`, one line) follows the same marker, also outside the touches list, so the existing placement tests keep reading the band.
  - Cold `/demo` at 390x844 (4x CPU, fast-4G, brotli, 3 runs per variant).
