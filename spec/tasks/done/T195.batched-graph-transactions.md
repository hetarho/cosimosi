## goal

A launch or the first advance of the day costs a bounded number of round trips regardless of graph size.

## acceptance

- [x] Consolidation reads a scalar projection (ids, anchors, stage integers, stage-text presence, decay-stage count) and fetches text only for memories whose decay stage crosses
- [x] Decay-text fills, provenance appends, activation inserts, neuron upserts and regen enqueues run as UNNEST batches chunked by `persistence.graph_write_batch_size`
- [x] Launch reads neuron co-activation dates once and passes them to achievement progress
- [x] Signup settlement stops re-running after it completes: `users.signup_settled_at` is set in the settlement transaction once every leg reports applied or not applicable, and `SettleSignup` returns early when set; while unset, behavior is unchanged
- [x] `internal/memory/pg/statement_count_integration_test.go` with a pgx tracer: a 5-memory launch issues the same statement count at 10 and 100 neurons; a 2,000-memory stage advance issues at most ceil(2000 / batch) statements per batched write
