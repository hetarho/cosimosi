## result
- outcome: Guide captions keep Korean words whole. The web caption paragraph carries `break-keep wrap-break-word text-balance` (keep-all, break-word, balanced), the UI-6 recipe the landing hero uses (`break-keep … text-balance`). The mobile caption `Text` sets `lineBreakStrategyIOS="hangul-word"`, which React Native 0.86 supports. On the demo, "회상 전후를 비교하고 우주로 돌아오세요." and "다시 찾지 않은 별은 어두워지고" now break between words at 1440x900 and 390x844. Size, colour, placement and the band budget are unchanged.

- limits: Android keeps syllable breaking. React Native 0.86's `Text` exposes only `textBreakStrategy` (simple/highQuality/balanced) and `android_hyphenationFrequency`, and neither keeps a Hangul word whole. Android's own `LineBreakConfig` word style (API 33+) is not exposed to React Native. iOS was verified by the prop assertion only: no simulator run in this lane.
