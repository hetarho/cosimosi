### 04. Change: provider model dropdown from live model listing

> A **change proposal** (a WHAT delta) that modifies the already-shipped behavior of [plan/58.admin-console](../../plan/58.admin-console.md).
> Filled by /cosimosi:create-change through a user interview — a reviewable doc, not a one-line prompt.
> The STEPS live in the job that /cosimosi:create-change-job creates. Write it in English.

#### As-is

The admin console's model selection (`ModelSelectSection` → `CapabilityRow`) renders a provider
`<select>` built from `ListProviderKeys` (keyed + supports + implements the capability) and a
**free-text model field**. `SetAIConfig(capability, provider, model)` validates the provider slot
but takes the model string as-is; an empty model falls through to the adapter default.

Nothing tells the operator which model ids the selected provider currently serves. They must know
the exact vendor id and type it by hand; a typo, a retired id, or a wrong-capability id is accepted
at save time and only surfaces later as a failing live call (e.g. the first `SplitDiary`).

#### To-be

- **New admin RPC `ListProviderModels(provider, capability)`** on `AdminService`, admin-gated like
  its siblings. It returns the provider's currently served model ids for that capability as a
  vendor-neutral list (`id` + optional display name). The server resolves the provider's stored
  key and queries the **vendor's live model-listing endpoint**; the adapter package owns all
  vendor knowledge (endpoint path, auth header, response shape, capability filtering) — exact
  endpoints confirmed at implement, per plan 28's adapter-ownership rule. A vendor with no
  listing endpoint (voyage) answers from its adapter-owned curated set instead.
- **FE model control becomes a dropdown** fed by `ListProviderModels` for the selected provider:
  - The currently configured model is preselected; if it is not in the fetched list it still
    appears as a selectable entry marked unlisted — never silently dropped.
  - A manual-entry escape hatch remains (a "custom id" option revealing the text field): the
    listing is advisory, and a missing key, a vendor outage, or a brand-new model must never
    block configuration. When the listing call fails, the control degrades to the text field
    with an inline notice.
  - Empty model keeps meaning "adapter default", exactly as today.
- **`SetAIConfig` stays advisory-free**: it does not validate the model against the live list.
  The dropdown improves input, not the save contract.

#### Scope / Non-goals (regression boundary)

Changes: `AdminService` proto (+1 read-only RPC), provider adapter packages (+ model-listing entry
point), `api-client` bindings, `admin-ai-config` feature UI.

Must NOT change:

- `SetAIConfig` / `GetAIConfig` / `ListProviderKeys` contracts and validation behavior.
- Key storage/encryption and the no-raw-key-on-the-wire rule ([plan/58](../../plan/58.admin-console.md)).
- The runtime adapter rebuild (fingerprint/cache) path.
- Non-goals: no server-side cache of vendor listings (admin-only, on-demand traffic; the FE query
  cache is enough — so no new `spec/values.yaml` key), no model metadata beyond id/display name,
  no mock-provider listing, no mobile surface (the admin console is web-only).

#### Acceptance Criteria

1. With a valid DeepSeek key stored, the LLM capability row offers DeepSeek's currently served
   model ids in a dropdown, fetched live from the vendor via `ListProviderModels` — no model
   catalog hardcoded in FE or i18n.
2. The same holds for Anthropic (LLM) and voyage (embedding; adapter-owned curated set).
3. The saved model is preselected; a configured id absent from the listing renders as an
   unlisted-but-selectable entry.
4. If the listing fails (no key, vendor error), the row degrades to manual text entry with an
   inline notice, and saving still works.
5. Manual entry stays available even when the listing succeeds, and saving an unlisted id is
   accepted exactly as today (`SetAIConfig` unchanged).
6. `ListProviderModels` is admin-gated and neither requires nor returns a raw API key on the wire.
